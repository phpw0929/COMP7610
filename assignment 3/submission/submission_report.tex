\section*{2. Custom function and additional logic}
\textbf{Custom function -- \code{applyForClubWithdrawal()}}. An active member can withdraw immediately. The function burns the caller's entire CPT balance, sets \code{activeMember} to false, sets \code{hasWithdrawn} to true, and emits \code{ClubWithdrawal} event. A withdrawn member cannot register again or receive rewards.

\textbf{Additional functional logic.} The system also provides: 

\begin{itemize}
  \item Member registration through \code{registerMember()}; 
  \item Whole-number CPT transfers using the inherited ERC-20 \code{transfer()}; 
  \item Owner-only single and batch CPT rewards through \code{mintCPT()} and \code{distributeCPT()};
  \item Campus-Memo minting. Each NFT costs 100 CPT, which is burned directly, and token IDs run from 1 to 10. NFT transfers use standard ERC-721 behavior. Events record registration, rewards, withdrawal, contract linking, and NFT minting.
\end{itemize}
